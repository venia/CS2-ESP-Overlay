Полный отчет по проекту CS2 ESP Overlay

Статус: В процессе разработки
🎯 Общая цель проекта
Создать ESP (Extra Sensory Perception) оверлей для CS2, который отображает информацию о противниках поверх игрового экрана:

Прямоугольники вокруг игроков (Box ESP)

Полоски здоровья (Health Bars)

Информация о команде (враг/союзник)
